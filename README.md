# 🏆 FanQuest: Agentic Tournament Hub

**FanQuest** is the fan engagement layer of the Agentic Sports Ecosystem, powered by **Google Gemini 1.5 Pro**. It transforms passive sports viewing into an active, gamified experience where fans participate in live predictions, complete tactical quests, and earn rewards guided by an AI Coach.

## 🔗 Live Deployment
[**View Live Hub**](https://fanquest-service-94343063153.asia-south1.run.app/)

---

## 🎮 Key Features
*   **AI Command Module**: A sophisticated AI Fan Coach that uses an "Observe-Reason-Act" loop to analyze a user's loyalty and offer personalized, dynamic quests.
*   **Live Prediction Engine**: Real-time match prediction functionality (e.g., LIV Win, Draw, MUN Win) with immediate visual feedback via a high-performance confetti burst engine.
*   **Gamified Progression**: Experience Points (XP), Fan Coins, and a digital "Reward Vault" for unlocking cosmetic profile upgrades.
*   **Premium Visuals**: High-gloss, dynamic UI featuring team-specific neon glows, holographic grids, and interactive modal displays.

## 🛠️ Technology Stack
*   **Frontend**: HTML5, Vanilla JavaScript, CSS3 (Advanced Glassmorphism & Keyframe Animations)
*   **AI Integration**: Simulated Gemini 1.5 Pro Reasoning Loop
*   **Deployment**: Docker, Nginx, Google Cloud Run
*   **Global Services**: Google Translate API

## 🚀 Quick Start (Local Development)

1. Clone the repository:
   ```bash
   git clone https://github.com/vishnu-priya99/fanquest-hub.git
   cd fanquest-hub
   ```
2. Run with Docker:
   ```bash
   docker build -t fanquest .
   docker run -p 8081:80 fanquest
   ```
3. Open `http://localhost:8081` in your browser.
