# 🏆 FanQuest: Agentic Tournament Hub
**An Official Submission for the Google Agentic Premier League Competition**

**FanQuest** is the interactive fan engagement layer of the Agentic Sports Ecosystem. It transforms passive sports viewing into an active, gamified experience where fans participate in live predictions, complete tactical quests, and earn rewards guided by an advanced AI Coach.

## 🔗 Live Deployment (Hosted on Google Cloud)
[**View Live Hub**](https://fanquest-service-94343063153.asia-south1.run.app/)

## ☁️ Powered by Google Cloud & AI
This gamified ecosystem relies heavily on Google's world-class infrastructure and AI capabilities:
*   **Google Gemini 1.5 Pro**: Powers the "AI Command Module". It utilizes an "Observe-Reason-Act" agentic loop to track user loyalty and generate highly personalized, dynamic quests.
*   **Google Cloud Run**: Ensures ultra-low latency and massive scalability. The stateless containerized architecture allows the platform to handle millions of simultaneous fan interactions globally.
*   **Google Translate API**: Provides seamless, real-time localization so football fans anywhere in the world can compete in their native language.
*   **Google Fonts**: Optimized typography ('Outfit', 'Inter') for a high-performance web experience.

## 🎮 Key Features
*   **AI Command Module**: A holographic AI Fan Coach offering predictive analysis and dynamic reward multipliers.
*   **Live Prediction Engine**: Real-time match prediction functionality (e.g., LIV Win, Draw, MUN Win) with immediate visual feedback via a high-performance confetti burst engine.
*   **Gamified Progression**: Experience Points (XP), Fan Coins, and a digital "Reward Vault" for unlocking cosmetic upgrades.
*   **Premium Visuals**: High-gloss UI featuring team-specific neon glows, holographic grids, and tactile animations.

## 🚀 Quick Start (Local Development)
1. Clone the repository:
   ```bash
   git clone https://github.com/vishnu-priya99/fanquest-hub.git
   cd fanquest-hub
   ```
2. Run with Docker:
   ```bash
   docker build -t fanquest .
   docker run -p 8081:80 fanquest
   ```
3. Open `http://localhost:8081` in your browser.
